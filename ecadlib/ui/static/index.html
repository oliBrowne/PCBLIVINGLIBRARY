Welcome to ecadlib

ecadlib turns a BOM into a checked parts library for Altium and KiCad. Nothing is in this workspace yet. Three ways to start:

  1. Try it with a sample BOM: seven common parts, built from ecadlib's own standard parts. Offline, no API key, about a minute.
  2. Drop your own BOM anywhere on this page (CSV or XLSX from Altium, KiCad or a spreadsheet).
  3. Run the setup check to see which part sources and tools are ready.

    Drop a BOM here (CSV or XLSX), or click to choose a file.
    Altium, KiCad and spreadsheet BOMs work. Columns such as Designator, Comment, MPN, Manufacturer, LCSC, Value and Footprint are matched automatically.

      2Fill the library

      Finds every missing symbol and footprint (official KiCad libraries, then EasyEDA, then the datasheet), converts them to Altium files and checks each part before release. Parts that fail a check are held back from Altium 365 until you look at them.

        There is no login: ecadlib is a local tool, so whatever name you type is recorded as given with each approval, rejection or release override (in the plan and in approvals_audit.jsonl). Sign-off is enforced only when an approvals.json sits next to the plan; a rejection always holds the part.

        3Send to Altium

        Pick one way in: a database library (DbLib) you open in Altium Designer, plain .SchLib / .PcbLib files, or managed components in an Altium 365 workspace.

        Database library (DbLib)

        After step 2: a .DbLib, its Excel table (.xlsx, also as .csv) and the ready parts' .SchLib / .PcbLib, in altium/<BOM>/; held parts stay out. Open the .DbLib in Altium Designer (it needs the Access database engine). Before step 2: a draft from the BOM check (SQLite and Excel tables, no symbols or footprints yet).

        Altium library files

        Converts this BOM's footprints from your KiCad libraries to .PcbLib and writes generic Resistor and Capacitor .SchLib symbols. Footprints you approve here get a .PcbLib automatically.

        Altium 365 workspace

        Plans one managed component per part. A part is ready once its .SchLib and .PcbLib exist.

        Footprint generator

        IPC-7351B land patterns from datasheet dimensions. You preview each one; it is only saved (KiCad .kicad_mod and Altium .PcbLib) when you approve it.

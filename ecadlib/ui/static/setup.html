ecadlib setup

open ecadlib →

Four short steps. Nothing here needs a terminal, and you can come back to this page any time (the Setup button in the ecadlib window, or /setup).

1AI model

The model reads datasheets for parts no library has. You pay the provider directly; ecadlib is free and sends nothing anywhere else.

Stored only on this computer, for your account. Never in your library or project files. Get a key

2Your tools

What this computer has, and which tool you make libraries for.

3Folders

A new folder is fine; ecadlib creates it.

ecadlib reuses parts from them and learns your naming. Copy a folder's path from the Explorer address bar.

4Add ecadlib to Altium and KiCad

An "add part from MPN" command inside your tool. Optional: everything also works from this web page.

+Optional keys

Only for the features named. Leave them empty if you do not use them.

Done?

Open ecadlib and drop a BOM (CSV or Excel, as Altium or KiCad export it) on the first card.

# because tests use them as fixtures; they are not what the generator makes today.

# 0.025 mm further in). That residual is the example spec's body numbers, not the IPC maths: the spec uses
# a generic datasheet outline (terminal 0.25 +/-0.10, width 0.50 +/-0.05) while KiCad builds C_0402 from
# IPC-SM-782 sizes (terminal 0.10-0.30, width 0.40-0.60). With KiCad's sizes the generator gives KiCad's
# pads exactly. An earlier copy of this file showed 0402 pads ~0.1 mm shorter and ~0.08 mm further in: that
# was the first prototype's small-chip fillet table, since corrected. See docs/footprint-rules.md
# ("Comparing with KiCad's library").

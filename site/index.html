02How it works

BOM in, library out.

One command, or one button in the local web UI. Every part ends up ready, or held with the reason and the fix.

  1. 01 · check

    Read the BOM

    Altium, ActiveBOM, KiCad or a hand-made sheet. Each line is matched against your library: have it, can fetch it, must draw it, DNP.

  2. 02 · fetch

    Find what exists

    Official KiCad libraries first, then EasyEDA and your own folders, converted to Altium with pads, pins and 3D bodies.

  3. 03 · draw

    Read the datasheet

    A model reads the package drawing into numbers. Code, not the model, turns the numbers into an IPC-7351B land pattern.

  4. 04 · prove

    Check every part

    Cross-checked reads, a visual proof against the drawing, a release check. Anything in doubt is held for a person.

  5. 05 · release

    Send it to your tool

    Altium 365 through Nexar, .SchLib / .PcbLib, a DbLib, or KiCad symbols, footprints and lib tables. Both always match.

04Workflow

      
Right inside Altium and KiCad.

      
You never leave your design tool. ecadlib adds an ecadlib menu to Altium and an action plugin to KiCad. Ask for a part, and it comes back as a library part you can place.

    05Your model
    
      
    Bring your own key.
    Use any model.
    
      
    There is no account, hosted service or telemetry. ecadlib talks only to the model you configure, with a key from your own environment. Claude is the default; OpenAI, OpenRouter, Gemini and local models through Ollama or LM Studio work too.
    
      
    Guide rails scale with the model. A small local model gets the work in small checked steps, JSON repair and worked examples. A frontier model gets one structured call and nothing that narrows it.

    06Where it lands
    
      
    Altium 365 first. KiCad too.
    
    
    
    
    
      
    
        
    altium
    
        
    Altium Designer and Altium 365
    
        
      
          
    • Components released to an Altium 365 workspace through Nexar, with a dry run first
      • 
          
    • .SchLib and .PcbLib written in pure Python, read back before release
      • 
          
    • Database libraries (SQLite or Excel with a .DbLib)
      • 
          
    • A menu inside Altium: add a part by MPN, check the project's BOM
      • 
        
    
      
    
      
    
        
    kicad
    
        
    KiCad
    
        
      
          
    • .kicad_sym, .pretty footprints and library tables
      • 
          
    • A KiCad database library and a PCM package
      • 
          
    • Tested in real KiCad: every package spec loads in pcbnew with the same pads
      • 
          
    • Parity check: the KiCad and Altium output are read back and compared part by part
      • 
        
    
      
    
    
    
    
    
      
    web ui
    A local page
    ecadlib ui opens it on your machine. Drop a BOM in, fill the library, sign parts off. A team server adds sign-in and roles.
    
      
    mcp
    An agent's tools
    ecadlib mcp lets Claude or another agent check a BOM and draft footprints in conversation.
    
      
    cli
    Scripts and CI
    Every step is a command with --json, so it fits a pipeline or a weekly job.
    
    
    
  
    

  
  
    
    
    
      
    
    
    
    
      
    07Living
    
      
    It keeps the library current.
    
      
    A weekly upkeep run checks lifecycle and stock with Nexar, DigiKey, Mouser and JLC, watches the KiCad sources your parts came from, and compares your Altium 365 workspace with the plan. It reports only what is new, in one issue or one pull request.
    
      
      
        
    • Parts that went NRND, last-time-buy or end of life
      • 
        
    • Upstream footprints whose pads moved, reconverted with a real diff
      • 
        
    • Library updates that never silently change a released part
      • 
      
    
    
    
  
    

  
  
    
    
    
      
    08Quick start
    
      
    Two minutes, offline, no keys.
    
      
    The demo builds a small library from a bundled BOM with the built-in standard parts, so you can see the whole flow before you set anything up.
    
    
    
    
    
      
    ~/libraries
    

    # from a checkout (Python 3.10+)
git clone https://github.com/oliBrowne/PCBLIVINGLIBRARY ecadlib && cd ecadlib
pip install -e .
ecadlib demo       # a 7-part library in ./ecadlib-demo, about a second
ecadlib init       # your tool, your libraries, your sources
ecadlib ui         # or do it all in your browser
